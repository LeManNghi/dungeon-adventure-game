# Hầm Ngục Tàn Hỏa

**Hầm Ngục Tàn Hỏa** là game phiêu lưu roguelike 2D theo lượt, mang phong cách pixel art. Bạn vào vai một người thám hiểm tiến xuống pháo đài bị nguyền rủa, lần theo dấu vết nghi lễ và tìm đường sống giữa những sinh vật trong bóng tối.

Mỗi bước đi là một quyết định. Quan sát ý định của kẻ địch, chọn vị trí để né đòn, dụ chúng vào bẫy và cân nhắc lúc sử dụng tài nguyên. Khi bạn dừng lại suy nghĩ, thế giới cũng chờ bước tiếp theo.

## Điểm nổi bật

- Hầm ngục thay đổi theo seed, với các phòng, hành lang và đường tắt để khám phá.
- Chiến đấu theo lượt trên lưới; những đòn mạnh của địch có tín hiệu báo trước.
- Sương mù che vùng chưa khám phá, cùng minimap ghi nhớ những nơi đã đi qua.
- Bẫy gai gây sát thương cho cả người chơi lẫn quái vật.
- Tàn hỏa tăng sức mạnh và bình máu giúp bạn tiếp tục hành trình.
- Chết sẽ kết thúc lượt chơi; bạn có thể thử lại cùng hầm ngục hoặc khám phá một seed mới.

Bản chơi hiện tại diễn ra trong một tầng gồm chín phòng. Hãy tìm cầu thang để hoàn thành chuyến thám hiểm — bạn có thể lựa chọn giao chiến hoặc tìm cách vượt qua kẻ địch.

## Chạy dự án

Khuyến nghị Node.js 22.15 trở lên. Cài dependency bằng `npm install` khi cần.

```sh
npm run dev
npm run build
npm test
npm run playtest
```
